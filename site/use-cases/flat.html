How this page uses AR Quick Look

A button inside AR

The scan is a .usdz file from RoomPlan. Its link gives the banner in AR a title, a subtitle, a price and a button with the page's own words: callToAction. A tap on that button closes AR and sends a message to the link, and the page opens the booking form. 

<a rel="ar" href="/models/room.usdz#callToAction=Book%20a%20viewing&checkoutTitle=Studio%20flat%2C%2034%20m%C2%B2&checkoutSubtitle=Harbour%20Street%2011&price=%E2%82%AC289%2C000">
  <img src="/shots/room.webp" alt="…">
</a>
link.addEventListener("message", (event) => {
  if (event.data === "_apple_ar_quicklook_button_tapped") {
    openBookingForm();
  }
});
